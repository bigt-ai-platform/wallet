# Predict 演示 — 中国市场示例（中文）

**其他演示：** [美国（English）](predict.md) · [德国（Deutsch）](predict.de.md) · 设计与威胁模型：[../prediction-market.md](../prediction-market.md)

三个面向中文用户的示例市场，各对应 **Predict（预测）** 标签页支持的一种市场形态：

1. **二元**市场，2-of-3 裁决委员会；
2. **多结果**市场（2–16 个结果），裁决委员会；
3. **质押预言机**市场，任何人都可以提出结果。

每个市场都给出创建表单的确切填写值、书面裁决规则，以及从创建到兑付的完整流程。

> **仅为测试网演示，不是真钱产品。** 抵押品是预测测试链上的原生 BIG（`bc`）。
> 在中国大陆，除国家批准的福利彩票、体育彩票外，以真钱押注事件结果属于违法赌博；
> 本演示不得以法币或任何可兑换法币的资产提供给大陆用户。演示题目只选用公开的
> 经济统计和文化消费数据，刻意避开政治类话题。参见
> [设计文档 §8](../prediction-market.md#8-out-of-scope)。

## 准备工作

- **PQ（ML-DSA）钱包。** 预测相关操作不接受 EC 钱包。
- **预测链上的 BIG。** 用于手续费和抵押。App 目前还没有跨链（peg-in）界面，
  演示钱包需由运营方在预测链上注资。
- **创建市场需要授权。** 创建者的密钥必须有权签署预测链的代币域。交易、
  裁决、争议、投票和兑付对所有已注资的 PQ 钱包开放。
- **委员会地址。** 委员会模式需收集各裁决人的十六进制钱包地址。3 名裁决人时，
  需 **2 个一致的裁决**（多数，`size/2 + 1`）才会生效。
- **单位。** 供应量、保证金和订单簿价格都是**链上原始单位**。一份获胜份额
  恰好兑付 1 个单位抵押品，所以价格相对 1 个抵押单位的比例就是市场隐含概率。
  App 不会换算成分或百分比。
- **下表天数按 2026-10-23 创建计算。** “Resolution days”可填小数，请按实际日期重新计算。

## 市场 1 — 2026 年第四季度 GDP（二元，委员会）

**问题：** *国家统计局首次公布的 2026 年第四季度国内生产总值同比增速是否不低于 5.0%？*

| 表单字段 | 填写值 |
|---|---|
| Question | `国家统计局首次公布的 2026 年第四季度国内生产总值同比增速是否不低于 5.0%？` |
| Outcomes | `是` / `否`（每行一个） |
| Collateral | `bc` |
| Supply | `1000000` |
| Resolution days | `89`（→ 2027-01-20，在季度数据发布之后） |
| Dispute window (s) | `86400`（24 小时） |
| Auto-invalid (s) | `2592000`（30 天） |
| Oracle | `committee` |
| Committee | 3 个裁决人地址，每行一个 |
| Bond（争议保证金） | `1000` |

**裁决规则。** 以国家统计局（stats.gov.cn）首次发布的数值为准，保留一位小数。
≥ 5.0% 为 **是**，否则为 **否**；之后的修订不计。若到裁决时间仍未发布，
裁决人等待发布；到自动作废期限仍无裁决时，市场作废（INVALID）。

## 市场 2 — 2027 年春节档票房（多结果，委员会）

**问题：** *2027 年春节档（除夕至正月初六）全国电影总票房（含服务费）落在哪个区间？*

| 表单字段 | 填写值 |
|---|---|
| Outcomes | `低于60亿元` / `60亿至80亿元` / `80亿至100亿元` / `100亿元及以上` |
| Collateral / Supply | `bc` / `1000000` |
| Resolution days | `120`（→ 2027-02-20，档期结束后） |
| Dispute window / Auto-invalid (s) | `86400` / `2592000` |
| Oracle / Committee / Bond | `committee` / 3 个地址 / `1000` |

**裁决规则。** 以国家电影局公布的春节档总票房为准；未公布时以灯塔专业版
档期汇总为准（裁决人须在争议窗口内注明数据来源）。区间下限包含、上限不包含，
例如恰好 80 亿元属于 `80亿至100亿元`。

结果标签不能包含逗号，不能重复，最长 40 个字符。拆分（split）C 个抵押品会得到
**每个**结果各 C 份。

## 市场 3 — 2026 年 12 月 CPI（二元，质押预言机）

**问题：** *国家统计局公布的 2026 年 12 月全国居民消费价格指数（CPI）同比涨幅是否为正？*

| 表单字段 | 填写值 |
|---|---|
| Outcomes | `是` / `否` |
| Collateral / Supply | `bc` / `1000000` |
| Resolution days | `84`（→ 2027-01-15，在月度数据发布之后） |
| Dispute window (s) | `86400` |
| Auto-invalid (s) | `1209600`（14 天） |
| Oracle | `staked`（委员会留空） |
| Bond（提议保证金） | `5000` |
| Vote window (s) | `172800`（48 小时） |

**裁决规则。** 以国家统计局发布的同比涨幅为准，保留一位小数。严格大于 0.0%
为 **是**；0.0% 或为负均为 **否**。

## 操作流程（三个市场相同）

1. **创建。** 预测标签页 → **Create market** → 按表填写 → 提交。App 为每个结果
   铸造固定供应量的代币，创建合约代币，并把全部供应量转入该市场的金库（vault）。
   市场显示为 **OPEN**。
2. **提供流动性（拆分）。** 输入数量并点击 **Split**：C 个 BIG 变成每个结果各
   C 份。市场开放期间可用 **Merge** 反向合并。
3. **交易。** 每个结果都有一个对 BIG 的订单簿（最优买价、卖价及数量）。
   **Buy**/**Sell** 会打开预览，显示预计成交、限价和滑点（0–10%，默认 0.5%）。
   报价 30 秒后失效，提交时会重新读取订单簿。这些是可吃单的限价单，未成交部分
   会挂在订单簿上。
4. **裁决。** 过了裁决时间，市场显示 *resolution due*。
   - *委员会（市场 1–2）：* 每位裁决人点选结果，多数一致后市场变为
     **PENDING**，争议窗口开始。
   - *质押（市场 3）：* 任何人都可以提出结果，并质押不少于提议保证金的 BIG，
     市场变为 **PENDING**。
5. **争议。** **PENDING** 期间，任何人都可以质押保证金提出不同结果。
   - *委员会：* 保证金（≥ 争议保证金）支付给裁决人，原有裁决清空，由委员会
     重新裁决。
   - *质押：* 挑战者（不能是提议者）质押不少于提议保证金，市场进入
     **VOTING**；持有人在投票窗口内为任一方质押 BIG。质押权重多的一方胜出，
     胜方取回质押并按比例分得败方保证金；平票则市场作废。
6. **终局。** 窗口内无人争议即为 **FINAL**。若到“裁决时间 + 自动作废”仍无人
   裁决，市场以 **INVALID** 终结。
7. **兑付。** **FINAL** 市场中，**Redeem** 按 1:1 把获胜份额换回 BIG。
   **INVALID** 市场中，按完整组合（每个结果各一份）兑换 1 个 BIG，
   多余的单个份额保留在钱包中。

之后可用 **open / resolving / final / mine** 筛选和搜索框找回市场；*mine*
显示你持有份额的市场。

## 自建中国市场的检查清单

- **只指定一个权威来源**和确切口径：国家统计局或国家电影局，首次发布还是修订值。
- **写清边界。** 恰好等于临界值时归哪一方？
- **规定缺失情形。** 数据延迟或停发时怎么办：等到自动作废，还是裁决为 INVALID？
- 裁决时间要设在数据**发布之后**，争议窗口要留足人工核对的时间。
- 避开政治、个人隐私等敏感题目，不接入法币或可兑换法币的抵押品。
