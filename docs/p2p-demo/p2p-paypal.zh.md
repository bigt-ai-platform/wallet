# FIAT（法币）结算 — 用 PayPal（USD）兑换 BIG

**术语。** FIAT = 法币；USD = 美元；CNY = 人民币；**PayPal** 是收款方式之一。

**这是什么。** 与微信 / 支付宝 / 银行一样，PayPal 也是钱包内直接与卖家交换法币的方式，区别是它使用 **美元（USD）**，收款账户是 **PayPal 邮箱**。卖家的 BIG 同样先放进 **2-of-3 托管地址**，买家把美元直接付给卖家，卖家在自己的 PayPal 账单上确认后释放 BIG。平台不保管资金，也不经手法币。

本演示：卖家挂单出售 **BIG**，买家以 **PayPal USD** 付款。

- 汇率：**BIG/USD = 0.01**
- 挂单：**10,000 BIG → 100 USD**
- 收款方式：**PayPal**

在 **P2P → 我的交易 → 发布卖单** 中选择 **PayPal** 时，法币会自动切换为 **USD**；选择微信 / 支付宝 / 银行时则自动为 **CNY**。

## 流程一览

```
待撮合 → 已匹配 → 托管已锁定 → 待付款 → 已付款待确认 → 已确认收款 → 托管已释放 → 已完成
```

可选路径：付款后如果双方有争议，可以冻结交易并提交争议，由平台协助裁决（放币给买家或退款给卖家）。

| # | 步骤 | 操作方 |
|---|---|---|
| 1 | 卖家保存 PayPal 收款档案 | 卖方 |
| 2 | 卖家挂单 BIG，报价 USD | 卖方 |
| 3 | 买家购买并提供收款地址 | 买方 |
| 4 | 卖家为托管注资 | 卖方 |
| 5 | 买家查看付款说明 | 买方 |
| 6 | 买家在 PayPal 付款，用交易号认领 | 买方 |
| 7 | 卖家在自己的 PayPal 账单确认 | 卖方 |
| 8 | **卖家释放 BIG** | **卖方 + 平台共同签名** |
| 9 | *可选：* 争议由平台协助裁决 | 平台 |

---

## 1. 卖家保存 PayPal 收款档案

卖家打开 **P2P → 我的交易**，在收款方式中选择 **PayPal**，输入户名与 **PayPal 邮箱**。这些信息只在成交后向买家展示，不会出现在公开订单簿里。

![卖家保存 PayPal 收款档案](assets/screenshots/p2p-paypal-01-profile-zh.png)

---

## 2. 卖家挂单 BIG（USD 报价）

卖家在 **发布卖单** 里填写代币（`bc`）、数量 **10,000**、价格 **0.01**、法币 **USD**、收款方式 **PayPal**，然后发布。

卖单出现在公开订单簿中，状态为 **待撮合**。

![以 paypal / USD 挂出卖单](assets/screenshots/p2p-paypal-02-order-zh.png)

---

## 3. 买家匹配订单

买家打开卖单，填写接收 BIG 的地址，确认购买。此时不需要填写 PayPal 信息。

应用为这笔交易创建唯一的交易号并准备托管地址；状态变为 **已匹配**。

![买家填写接收地址](assets/screenshots/p2p-paypal-03-match-zh.png)

![创建于已匹配的交换](assets/screenshots/p2p-paypal-04-matched-zh.png)

---

## 4. 卖家将 BIG 锁定到托管

应用生成一个 **2-of-3 托管地址**：卖家、买家、平台三方中任意两方同意才能动用资金。卖家把 **10,000 BIG** 转入该地址，并粘贴转账的交易哈希；应用确认后，状态变为 **托管已锁定**。

买家在支付美元之前就能看到 BIG 已经被锁定。

![卖家粘贴托管交易哈希](assets/screenshots/p2p-paypal-05-escrow-lock-zh.png)

![托管已锁定](assets/screenshots/p2p-paypal-06-escrow-locked-zh.png)

---

## 5. 买家查看支付说明

买家点击 **支付详情**，会看到：

- 收款户名
- **PayPal 邮箱 / 账号**
- 精确金额 **100 USD**
- 这笔交易专属的**备注码**
- 付款截止时间

付款说明只向已匹配的买家展示。

![PayPal 付款说明：户名、邮箱、100 USD、备注码](assets/screenshots/p2p-paypal-07-buy-locked-zh.png)

![付款详情面板](assets/screenshots/p2p-paypal-08-instructions-zh.png)

---

## 6. 买家在 PayPal 付款并用交易号认领

买家在自己的 PayPal 应用中转账 **100 USD**，在备注中填入备注码，然后把 PayPal 交易号粘贴到 **交易单号**，按下 **我已付款**。

可以附加付款凭证图片；图片只保存在服务器端，不会写入链上。

![已输入交易号](assets/screenshots/p2p-paypal-09-payment-pending-zh.png)

状态变为 **已付款待确认**。BIG 仍然锁定，这只是买家的付款声明。

![已付款待确认](assets/screenshots/p2p-paypal-10-payment-claimed-zh.png)

> **PayPal 提示。** 付款时请选择「商品和服务」并保留交易号；个人转账的备注不一定出现在对账单上，因此卖家核对时以 **金额 + 时间 + 交易号** 为准。

---

## 7. 卖家在自己的 PayPal 账单上确认

卖家的卡片会显示买家的交易号。卖家只在 **自己的 PayPal 账单里确实看到这笔钱** 之后，才点击 **确认收到**。

![卖家核对交易号并确认](assets/screenshots/p2p-paypal-11-seller-confirm-zh.png)

状态变为 **已确认收款**。

---

## 8. 卖方释放托管

> **卖家请尽快释放托管。** 确认收款后应立即点击 **释放资金**。延迟释放会降低卖家评分；严重或多次延迟会把卖家标记为 **不安全**，影响后续订单。

卖家确认收款后点击 **释放资金**，平台共同签名，把 BIG 转到买家的收款地址。由于卖家已经直接收到美元，没有额外的法币打款步骤，交易随即完成。

![已确认收款 — 立即释放](assets/screenshots/p2p-paypal-12-payment-verified-zh.png)

![托管已释放](assets/screenshots/p2p-paypal-13-escrow-released-zh.png)

![已完成](assets/screenshots/p2p-paypal-14-completed-zh.png)

---

## 9. 可选：争议由平台协助裁决

如果双方对付款有争议（金额不符、未收到款、卖家延迟释放等），任何一方都可以冻结交易并提交争议。平台核对托管与付款凭证后，决定 **放币给买家** 或 **退款给卖家**。

卖家的败诉与反复延迟会记录在信誉中，严重时会被标记为 **不安全**。

---

## 为什么 PayPal 没有「用我的手机验证」

「用我的手机验证」通过读取本机支付应用来补充证据；买家侧目前只有 **支付宝 / 银行** 可以读取，而且只在卖家延迟释放或有争议时出现。**PayPal 没有读取支持**，所以 PayPal 交易只提供手动 **确认收到** 与 **申诉**。

---

## 对比：Binance P2P 与本次结算

| 功能 | Binance P2P | 本次结算 |
|---|---|---|
| 托管 | 平台托管 | **链上 2-of-3 托管**（卖方 + 买方 + 平台） |
| 法币确认 | 平台订单状态 | **卖家核对 PayPal 账单**，买家提供交易号 |
| 争议 | 平台客服裁决 | 应用内争议 + 平台裁决 |
| 支付方式 | 多通道 | 微信 / 支付宝 / 银行（CNY）· **PayPal（USD）** |
