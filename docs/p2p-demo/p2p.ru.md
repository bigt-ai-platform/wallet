# FIAT (фиатные деньги) — обмен BIG через WeChat / Alipay / банк или PayPal

**Термины.** FIAT = фиатные деньги; CNY = китайский юань; USD = доллар США; P2P = «равный равному» (напрямую между людьми).

**Что это.** В кошельке Bigtangle вы напрямую обмениваете **BIG** на фиатные деньги (WeChat Pay / Alipay / банковский перевод или **PayPal USD**). BIG продавца сначала попадают на **эскроу-адрес**, распоряжаться которым можно только при согласии двух из трёх сторон — продавца, покупателя и платформы. Покупатель переводит деньги напрямую продавцу, а продавец, убедившись в поступлении по своей выписке, освобождает BIG. Платформа не хранит ваши средства и не проводит через себя фиатные деньги.

**О скриншотах.** Скриншоты ниже сделаны в демонстрационной среде на реальном устройстве: суммы и хеши — демонстрационные данные, настоящие средства не задействованы.

В этом руководстве показано: продавец выставляет ордер на продажу BIG, покупатель покупает, средства блокируются в эскроу, покупатель платит, продавец подтверждает, BIG освобождаются, а также возврат по истечении срока. Курс **BIG/CNY = 0.01**, ордер **10 000 BIG → 100 CNY**.

## Обзор процесса

```
Ожидает подбора → Подобрано → Эскроу заблокирован → Ожидает оплаты → Оплата заявлена → Оплата подтверждена → Эскроу освобождён → Завершено
```

Каждый шаг отображается на карточке сделки в приложении; статус движется только вперёд, без пропусков и откатов.

Необязательный путь: если после оплаты у сторон возник спор, любая сторона может заморозить сделку и подать спор, и платформа поможет вынести решение (передать монеты покупателю или вернуть деньги продавцу).


**PayPal (доллары).** При выборе **PayPal** фиатная валюта автоматически переключается на **USD**, а счёт для получения меняется на адрес электронной почты PayPal; всё остальное происходит точно так же. Полная демонстрация — см. [p2p-paypal.zh.md](p2p-paypal.zh.md) → `assets/p2p-paypal.zh.mobile.pdf` (**10 000 BIG → 100 USD**).

## 1. Продавец сохраняет реквизиты для получения

Продавец открывает **P2P → Мои сделки**, выбирает способ получения (WeChat, Alipay, банк или PayPal) и указывает имя владельца и номер счёта (для PayPal — адрес электронной почты). Эти данные показываются покупателю только после заключения сделки и не попадают в публичный список ордеров.

![Продавец сохраняет реквизиты WeChat Pay](assets/screenshots/p2p-cny-wechat-01-profile-ru.png)

---

## 2. Продавец выставляет ордер на BIG

В разделе **Разместить ордер на продажу** продавец указывает токен (`bc`), количество **10 000**, цену **0.01**, фиатную валюту **CNY**, способ получения **WeChat**, а затем публикует ордер.

После публикации ордер появляется в публичном списке со статусом **Ожидает подбора**. Продавец может в любой момент отменить ещё не исполненный ордер.

![Ордер на продажу в wechat / CNY](assets/screenshots/p2p-cny-wechat-02-order-ru.png)

---

## 3. Покупатель подбирает ордер

Покупатель открывает ордер на продажу, указывает адрес для получения BIG и подтверждает покупку. На этом этапе реквизиты WeChat или Alipay указывать ещё не нужно — данные продавца для получения будут показаны этому покупателю отдельно после блокировки эскроу.

Приложение создаёт уникальный номер сделки и готовит эскроу-адрес; статус меняется на **Подобрано**.

![Покупатель указывает адрес для получения](assets/screenshots/p2p-cny-wechat-03-match-ru.png)

![Сделка создана и подобрана](assets/screenshots/p2p-cny-wechat-04-matched-ru.png)

---

## 4. Продавец блокирует BIG в эскроу

Для этой сделки приложение создаёт **эскроу-адрес 2-of-3**: распоряжаться средствами могут любые две стороны из трёх — продавец, покупатель и платформа, — и ни одна сторона не может забрать их единолично.

Продавец переводит **10 000 BIG** на этот адрес и вставляет в приложение хеш этой транзакции. После проверки суммы и адреса получателя статус меняется на **Эскроу заблокирован**. Покупатель ещё до оплаты фиатных денег видит, что BIG уже заблокированы.

![Продавец вставляет хеш эскроу-транзакции](assets/screenshots/p2p-cny-wechat-05-escrow-lock-ru.png)

![Эскроу заблокирован](assets/screenshots/p2p-cny-wechat-06-escrow-locked-ru.png)

---

## 5. Покупатель открывает инструкцию по оплате

Нажав **Детали оплаты**, покупатель увидит:

- имя владельца счёта продавца
- счёт для получения (номер WeChat / Alipay / банковского счёта или адрес электронной почты PayPal)
- точную сумму **100 CNY**
- **код назначения платежа**, предназначенный только для этой сделки
- срок оплаты

При переводе покупатель обязан указать код назначения платежа в комментарии. Статус меняется на **Ожидает оплаты**; если оплата не поступит до истечения срока, сделка истечёт, а средства будут возвращены.

![Инструкция по оплате: имя, счёт, 100 CNY, назначение платежа](assets/screenshots/p2p-cny-wechat-08-instructions-ru.png)

---

## 6. Покупатель платит CNY и заявляет об оплате

Покупатель переводит **100 CNY** в своём WeChat, указывает код назначения платежа в комментарии, затем вставляет номер транзакции (номер перевода) в поле **Номер транзакции** и нажимает **Я оплатил**.

Можно приложить изображение подтверждения оплаты; изображение хранится только на сервере и не записывается в блокчейн.

![Введён номер транзакции (номер перевода)](assets/screenshots/p2p-cny-wechat-09-payment-pending-ru.png)

Статус меняется на **Оплата заявлена**. В этот момент BIG всё ещё заблокированы — это лишь заявление покупателя об оплате.

![Оплата заявлена](assets/screenshots/p2p-cny-wechat-10-payment-claimed-ru.png)

## 7. Продавец подтверждает по своей выписке

На карточке сделки продавца отображаются номер перевода и комментарий, указанные покупателем. Продавец сверяет **сумму + назначение платежа + время + номер перевода** только в своей выписке WeChat и, только убедившись, что всё совпадает, нажимает **Подтвердить получение**.

Скриншот не является доказательством; ориентируйтесь на фактическое поступление на ваш счёт.

![Продавец видит номер перевода и предупреждение при подтверждении](assets/screenshots/p2p-cny-wechat-11-seller-confirm-ru.png)

Статус меняется на **Оплата подтверждена**.

![Оплата подтверждена](assets/screenshots/p2p-cny-wechat-12-payment-verified-ru.png)

## 8. Продавец освобождает эскроу

> **Продавцу следует освобождать эскроу как можно скорее.** После подтверждения получения сразу нажмите **Освободить средства**. Задержка освобождения снижает рейтинг продавца; серьёзные или повторяющиеся задержки помечают продавца как **ненадёжного** и влияют на последующие ордера.

Сразу после подтверждения получения продавец нажимает **Освободить средства**, платформа ставит со-подпись, и BIG переводятся на адрес получателя покупателя. Для освобождения достаточно подписи продавца и подписи платформы — ни одна из сторон не может распорядиться этими деньгами в одиночку.

Поскольку продавец получает деньги напрямую, дополнительного шага по переводу фиатных средств нет, и сделка сразу завершается.

![Эскроу освобождён](assets/screenshots/p2p-cny-wechat-13-escrow-released-ru.png)

![Завершено](assets/screenshots/p2p-cny-wechat-14-completed-ru.png)

Статус меняется на **Завершено**.

## 9. Необязательно: спор с помощью платформы

Если у сторон есть разногласия по оплате (сумма не совпадает, деньги не получены, продавец долго не освобождает средства и т. п.), любая сторона может заморозить сделку и подать спор. Платформа проверит эскроу и подтверждение оплаты и решит: **передать монеты покупателю** или **вернуть деньги продавцу**.

Проигранные споры и повторяющиеся задержки отражаются в репутации продавца, а в серьёзных случаях он помечается как **ненадёжный**.

---

## 10. Истечение срока или неудача → возврат

Если покупатель так и не оплатил, продавец может дать сделке истечь; BIG из эскроу вернутся продавцу без согласия покупателя.

Ни одна сторона не удерживает средства другой стороны.

---

## 11. Необязательно: «Подтвердить с моего телефона» (покупатель, задержка освобождения)

Это не обязательный шаг для обычного расчёта. Кнопка **«Подтвердить с моего телефона»** появляется у покупателя только если продавец задерживает освобождение (прошло больше **30 минут** после того, как покупатель заявил об оплате, или оплата подтверждена, но средства не освобождаются) **или** если открыт спор.

Она показывается только для **Alipay / банка**, поскольку на стороне покупателя можно прочитать историю переводов; WeChat уведомляет лишь получателя, а у PayPal нет моста чтения, поэтому для них кнопка не показывается. Покупатель один раз считывает данные со своего сопряжённого телефона, кошелёк подписывает результат и отправляет его; проверка отражается в репутации продавца, но не заменяет освобождение, которое продавец должен выполнить как можно скорее.

## Сравнение: Binance P2P и этот расчёт

| Функция | Binance P2P | Этот расчёт |
|---|---|---|
| Подтверждение фиата | Продавец нажимает «Подтвердить» (система репутации) | Продавец подтверждает по своей выписке, платформа освобождает монеты по процедуре |
| Хранение фиата | Платформа (покупатель → продавец) | Покупатель платит продавцу напрямую, платформа не проводит фиат |
| Эскроу | Внутренний реестр платформы | Эскроу 2-of-3 в блокчейне, публично проверяемый |
| Возврат | Обращение в поддержку | По истечении срока средства автоматически возвращаются продавцу |
| Разрешение споров | Ручная поддержка (несколько дней) | Спор в приложении + решение платформы (быстрее) |

```
Подобрано            14:20  Сумма фиксируется при подборе
Эскроу заблокирован  14:23  Продавец переводит BIG, приложение подтверждает поступление
Ожидает оплаты       14:24  Покупатель видит инструкцию по оплате
Оплата заявлена      14:25  Покупатель платит и указывает номер перевода
Оплата подтверждена  14:26  Продавец подтверждает по своей выписке
Эскроу освобождён    14:27  Продавец и платформа подписывают совместно, BIG уходят покупателю
Завершено            14:27  Сделка завершена
```
